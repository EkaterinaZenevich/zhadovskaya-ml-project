# Тематическая структура лирики Ю. В. Жадовской

Итоговый проект по машинному обучению.

## Цель проекта

Исследовать тематическую структуру лирики Ю. В. Жадовской в рукописном альбоме и двух прижизненных сборниках с помощью методов машинного обучения и сравнить семантическую структуру трёх источников.

## Что было сделано

В проекте проведены разведочный анализ корпуса и частотный анализ лексики, построены TF-IDF и семантические представления текстов, применены методы кластеризации KMeans, Agglomerative Clustering и DBSCAN.

Также были сопоставлены разные версии произведений, проведено отдельное сравнение семантической структуры трёх источников и обучен автоэнкодер для сжатия семантических представлений.

## Основной результат

Автоматическая кластеризация показала, что тематические группы в корпусе имеют размытые границы. При отдельном анализе трёх источников было выявлено крупное противопоставление двух условных семантических полюсов — «внешнего мира» и «внутреннего мира». Их соотношение в альбоме и первом сборнике оказалось близким, тогда как во втором сборнике распределение заметно отличается.
